# AmidTech LLC — amidtechgroup.com

Static website of AmidTech LLC (New Mexico, USA) — software development, web services, IT consulting and IT hardware supply.
Canonical address: https://www.amidtechgroup.com (the address without `www` redirects to it).

## Files

- `src/index.html` — **source** of the home page (bilingual). Edit this file, never `index.html` or `en.html`.
- `index.html` (French, `/`) and `en.html` (English, `/en`) — generated by `python3 scripts/build_site.py`.
- `terms.html`, `privacy.html`, `refund.html` (English) and `fr/…` (French), `404.html` — generated by `python3 scripts/build_legal.py` (texts are in that script, styles in `scripts/legal_style.css`).
- `scripts/build_pricing.py` — regenerates the pricing block inside `src/index.html`; run `build_site.py` afterwards.
- `api/chat.js` — website assistant (needs `ANTHROPIC_API_KEY`).
- `api/contact.js` — quote form (needs `RESEND_API_KEY`; without it the form opens the visitor's e-mail app).
- `news.json` — news bar, updated by `scripts/update_news.py` (GitHub Actions) from `data/announcements.json`.
- `vercel.json` — clean URLs, redirects, security headers. `og-image.png` — share image. `Liens.html` — links page.

`.github/workflows/build.yml` rebuilds the generated pages when the sources change.
Deployed automatically by Vercel on every push to `main`.
